Paste the **Description** block from each file into Grok Bot → Settings.
Name and Title are listed at the top of each file.

| File | Bot | Talks to |

| `floor-pm.md` | Floor PM | everyone; only bot that opens stages |

| `ops.md` | Ops | routines; Floor PM; Demo |
